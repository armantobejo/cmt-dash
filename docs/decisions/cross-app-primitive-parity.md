# Decision: cross-app primitive parity vectors (anti-circular testing)

Status: decided 2026-09-22 · Phase gate: supports PRD §8 P1–P5 parallel run

## Problem

The parallel run requires the Laravel app to be interoperable with the Python
app at the byte level: same `users`/`sessions` rows, same cookies, same
error bodies. The first cross-app check (login as a Python-created user)
exposed a PBKDF2 hash-length bug that every existing test missed — because
the old test computed its expected value *in PHP* (PHP-vs-PHP is circular).

## Rule

**No Laravel test may compute an expected value for a primitive the Python
app also produces.** Expected values are generated by executing the real
Python stack and written to:

```
laravel/tests/Fixtures/parity_vectors.json
```

by `tools/gen_parity_vectors.py` (runs `app.auth` constants, real FastAPI
validation via TestClient, real Starlette cookie rendering). Regenerate after
any change to the Python reference:

```
python tools/gen_parity_vectors.py          # write fixture
python tools/gen_parity_vectors.py --check  # exit 1 if stale (CI-able)
make parity-vectors / make parity-vectors-check
```

`laravel/tests/Feature/CrossAppVectorsTest.php` consumes the fixture. It
asserts PHP output == recorded Python output, and for unfixable platform
divergences pins the exact difference (never leaves it silent).

## Audit results (2026-09-22)

Fixed to match Python byte-for-byte:

| Primitive | Python | Laravel was | Fix |
|---|---|---|---|
| PBKDF2 | `dklen=32` → 64 hex | already fixed (507b208) | pinned in vectors |
| `str.capitalize` (seeder display_name) | first char upper, **rest lower** (`ADMIN→Admin`) | `ucfirst` (`ADMIN→ADMIN`) | `CmtAuth::capitalize()` |
| `cmt_session` cookie | **no Max-Age** (browser-session) | Max-Age = 8h | expire=0 |
| logout cookie | `delete_cookie` (Max-Age=0) | long-expiry overwrite | `cookie()->forget()` |
| `cmt_db` cookie | **no HttpOnly**, Secure from `CMT_COOKIE_SECURE` | HttpOnly + `session.secure` | matches now |
| 403 body | `{"detail":"Requires role >= X"}` | HTML error page | `JsonResponse` |
| missing login fields | FastAPI 422 `{detail:[{type,loc,msg,input}]}` | 200 re-render (Laravel validation) | manual 422, exact shape |

Pinned divergences (unfixable or harmless; asserted as known differences):

| Primitive | Python | PHP | Why OK |
|---|---|---|---|
| int-valued floats in JSON | `1.0` | `1` | PHP json_encode semantics; decoded value equal; P5 normalizer rounds floats |
| large-exponent floats | `1e+20` | `1.0e+20` | spelling only; P5 rounds to 4dp |
| isoformat micros=0 | `…:00+00:00` | `…:00.000000+00:00` | PHP `.u` always prints; ~1e-6 of writes; string ordering unaffected |
| `Set-Cookie` with Max-Age | Starlette: no `Expires` | Symfony: always adds `Expires` | same lifetime semantics; pinned |
| delete-cookie value | `=""` | `=deleted` sentinel | same browser instruction |
| 419 vs FastAPI behavior on tokenless POST | no CSRF anywhere | CSRF on all POSTs except `/set-db` | deliberate improvement, documented in P5 spec |

## Note on the 422 shape

FastAPI emits `"Field required"` with key order `type, loc, msg, input` and
`input: null` — reproduced exactly (verified against real FastAPI output, not
from memory). Laravel's own validator was bypassed because its messages are
not part of the Python contract.

43 Laravel tests green (15 vector tests, 174 assertions). Python suites
untouched.
